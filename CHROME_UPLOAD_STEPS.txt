MintList 2.0.0 - Chrome Web Store upload steps

Build the ZIP (run inside the project folder):
  zip -r MintList-2.0.0.zip manifest.json index.html popup.html options.html css js icons

Chrome Web Store:
1. Open the Chrome Web Store Developer Dashboard.
2. Click New Item (or open the existing listing and upload a new package).
3. Upload MintList-2.0.0.zip.
4. Fill in listing details, screenshots (1280x800), privacy practices and permission justifications (below).
5. Submit for review.

Local testing:
1. Open chrome://extensions and enable Developer mode.
2. Click Load unpacked and select the project folder.
3. Open a new tab.

Single purpose:
  MintList replaces the new tab page with a bookmark manager and lets users save pages to it.

Permission justifications:
- storage, unlimitedStorage: stores the user's pages, boards, links, settings and uploaded wallpaper images locally.
- tabs: reads the active tab's title and URL when the user saves it, lists open tabs in the "Open tabs" panel, and opens bookmarks in new tabs/windows.
- contextMenus: adds "Save to MintList" to the right-click menu.
- favicon: shows website icons from Chrome's local favicon cache next to each bookmark.
- bookmarks (optional permission): requested only when the user chooses "Import Chrome bookmarks"; used once to read the bookmark tree.

Data usage:
  No data leaves the browser. Optional sync uses chrome.storage.sync (the user's own Chrome profile). No remote code, no analytics.
